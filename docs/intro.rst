Introduction
=============

This is the official documentation for the BrushQuadX project. 
The BrushQuadX is a quadcopter drone that uses brushed motors and is designed for 
educational and hobbyist purposes. This documentation provides an overview of the 
project, tutorials for getting started, and detailed explanations of the concepts 
and components involved in building and operating the BrushQuadX.

Explore the sections of the documentation below:

1. **Drone Tutorial**  
   Learn more about the step-by-step tutorial for building the drone.  
   See the full guide in the :ref:`Drone Tutorial <drone_tutorial>` section.

2. **Controller Tutorial**  
   Learn more about the step-by-step tutorial for building the controller.  
   Check out the complete guide in the :ref:`Controller Tutorial <controller_tutorial>` section.

3. **Concepts**  
   Understand the fundamental concepts and principles behind the BrushQuadX design.
   See the full details in the :doc:`Concepts <concepts>` section.

4. **Prototypes**  
   Learn more about the various prototypes and the evolution of the design throughout the project.
   See the full details in the :ref:`Prototypes <prototypes>` section.

5. **Future**  
   See some of the future work planned for the BrushQuadX project.
   See the full details in the :ref:`Future <future>` section.
